# Validation

Run `npm install`, `npx playwright install chromium`, then `npm run check` and `npm test`.
The browser test uses a local HTTP server on port 8765 and isolated browser storage.
It does not touch production data. Internet access is required for the app's existing
html2canvas, jsPDF and font CDNs. Generated screenshots and PDFs are ignored by Git.

Covered workflows: initial frames; add and duplicate; immediate field persistence;
prompt copy; vertical preview; autoplay through every frame; 390/768/1440px layouts;
PNG generation; PDF generation with real libraries and parsed page counts;
legacy JSON import including image, dialogue, camera and custom properties;
image file selection; frame movement; empty boards; preservation of corrupt saved data;
and uncaught browser errors.

The sandbox blocked browser download persistence, so the test intercepts the final
PNG link and PDF save call to inspect generated bytes. The operating system's
download/save dialog still requires a manual smoke test outside the sandbox.

PDF exports rasterize browser-rendered text to retain Thai glyphs. The output is
multi-page and includes full prompts; PDF text is not selectable. Very long frame
content continues on another page. Music remains available in Preview and is not
embedded in a PNG or PDF.
